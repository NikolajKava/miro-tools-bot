# Видео из Telegram → каталог инструментов на Miro

Пересылаешь боту видео (reels, TikTok, Shorts) с подборкой инструментов для Claude Code — через несколько минут на доске появляется строка в сводной таблице и карточка с описанием, командой установки и ссылкой на официальный репозиторий по каждому инструменту.

Работает на GitHub Actions, своего сервера не нужно, ноутбук может быть выключен.

## Как устроено

```
Telegram ──пересылаешь видео──▶ бот
                                 │
        cron раз в 5 минут       ▼
GitHub Actions ──getUpdates──▶ скачивает файл (Bot API, до 20 МБ)
        │
        ├─ ffmpeg: контактные листы кадров
        ├─ claude -p: читает кадры, находит названия, проверяет по вебу
        ├─ Miro REST: карточка на инструмент, цвет по категории
        └─ отвечает отчётом в тот же чат
```

Логика разбора живёт в [.claude/skills/tiktok-tools/SKILL.md](.claude/skills/tiktok-tools/SKILL.md) — том же виде, в каком она работает локально.

**Ссылкой или файлом — работает и так, и так.** Обычно достаточно ссылки: проверено, что Instagram отдаёт публичные reels прямо на раннер GitHub, без кук и прокси ([probe-download.yml](.github/workflows/probe-download.yml) прогоняет эту проверку на любой ссылке).

Блокировки всё же случаются — площадки реагируют на объём и на конкретные IP. Если `yt-dlp` не справится, бот об этом напишет; тогда перешли само видео файлом. Из Instagram оно достаётся через «Download» в меню reels (есть не у всех роликов) или записью экрана. Ссылку в подписи к файлу стоит оставить — она попадёт в поле «Откуда».

## Настройка

### 1. Репозиторий

Залей эти файлы в репозиторий на GitHub. **Делай его публичным** — тогда минуты Actions бесплатны и безлимитны. В приватном репозитории cron раз в 5 минут съест бесплатные 2000 минут в месяц примерно за неделю. Секреты в публичном репозитории лежат зашифрованными и в логи не попадают.

### 2. Telegram-бот

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. Отправь боту любое сообщение (иначе он не сможет тебе отвечать).
3. Узнай свой chat_id: `curl "https://api.telegram.org/bot<ТОКЕН>/getUpdates"` → поле `message.chat.id`.

Канал вместо личного чата тоже работает — добавь бота администратором, тогда chat_id будет отрицательным числом.

### 3. Токен Claude

На своей машине:

```bash
claude setup-token
```

Выдаёт долгоживущий токен, работающий по подписке, — отдельный API-ключ и отдельный счёт не нужны.

### 4. Токен Miro

Нужен постоянный токен приложения:

1. https://miro.com/app/settings/user-profile/apps → **Create new app**. Создавать нужно в команде, где ты полноправный участник: гостям Miro эту кнопку не даёт.
2. Права: `boards:read`, `boards:write`.
3. Выключи истечение токена — иначе он умрёт через час.
4. Install app and get OAuth token → скопируй.

**Почему REST, а не MCP.** MCP-сервер Miro (`mcp.miro.com`) токены приложений не принимает — отвечает `403 token-not-provided`, ему нужен собственный браузерный OAuth, которого в CI нет. Проверено и то, что доступно через REST с таким токеном:

| Операция | Результат |
|---|---|
| Карточки и фреймы — создать, изменить, удалить | ✅ |
| Документы (`doc_format`) — прочитать | ✅ |
| Документы — создать или изменить | ❌ `app is not whitelisted` |
| Таблицы — создать | ❌ |

Поэтому каталог собран на карточках: заголовок, цвет по категории, описание со ссылками. Пишет их [scripts/miro_card.py](scripts/miro_card.py).

### 5. Секреты и переменные репозитория

Settings → Secrets and variables → Actions.

**Secrets:**

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `CLAUDE_CODE_OAUTH_TOKEN` | вывод `claude setup-token` |
| `MIRO_TOKEN` | access token приложения Miro |

**Variables:**

| Имя | Что это |
|---|---|
| `MIRO_BOARD_URL` | `https://miro.com/app/board/uXjVHx5ay_A=/` |
| `TELEGRAM_ALLOWED_CHATS` | твой chat_id — чтобы бот не работал на посторонних |

`TELEGRAM_ALLOWED_CHATS` пустой означает «принимать от кого угодно». Бот-токен по сути публичен: кто угодно, узнав имя бота, может ему написать. Заполни это поле.

### 6. Проверка

Actions → **Разбор видео из Telegram** → Run workflow. Затем перешли боту видео и подожди до пяти минут.

## Что стоит знать

**Задержка до 5 минут** — это минимальный интервал cron в GitHub, и по факту расписания иногда опаздывают ещё на несколько минут под нагрузкой. Если станет мешать, лечится вебхуком: Telegram шлёт апдейт в бесплатный Cloudflare Worker, тот дёргает `repository_dispatch` — запуск получается мгновенным, а минуты Actions тратятся только на реальные видео.

**Лимит 20 МБ** — ограничение Bot API на скачивание файлов ботом. Ролики до минуты в него укладываются, длинные видео нет.

**Cron засыпает** — GitHub отключает расписания в репозитории без активности 60 дней. Для этого лежит [keepalive.yml](.github/workflows/keepalive.yml), который раз в неделю двигает файл-метку.

**Стоимость** — публичный репозиторий даёт безлимитные минуты, токены Claude идут по подписке. Отдельных счетов нет.
